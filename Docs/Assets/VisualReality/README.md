# Visual Reality Assets

Dokument-ID: RKWS-VISUAL-REALITY-ASSETS
Version: 1.0.0
Status: Accepted
Datum: 2026-07-04

## Zweck

Dieses Verzeichnis enthaelt Owner-Referenzen fuer die visuelle Richtung der Ablage-Linse.

Die Bilder sind keine fertigen UI-Vorgaben.

Sie definieren Wahrnehmungsqualitaeten:

- optische Materialitaet.
- Brechung.
- Tiefe.
- ruhige Raumoeffnung.
- weicher Einzug.
- Portal-Kontinuitaet.

## Referenzen

| Datei | Wahrnehmungsrolle |
| --- | --- |
| `reference-01-glass-lens.png` | Echte Glaslinse, ruhige physische Praesenz, Brechung. |
| `reference-02-light-tunnel.png` | Richtung und Durchgangsgefuehl, nicht als greller Sci-Fi-Effekt. |
| `reference-03-gravity-well.png` | Raum wird weich, tiefer und zieht das Ding kontrolliert hinein. |
| `reference-04-black-hole-portal.png` | Portalrand und Tiefe, nicht als bedrohliches schwarzes Loch. |
| `reference-05-mirror-lens-depth.png` | Spiegel-/Linsenraum, der eine andere Ablage hinter der Oberflaeche andeutet. |
| `reference-06-wormhole-surface.png` | Flaeche mit tiefer Oeffnung, nicht als Button oder Kreis. |

## Leitregel

```text
Der echte Desktop bleibt da.
Die Linse erzeugt Tiefe im Raum.
Sie ersetzt den Raum nicht durch ein Bild.
```
