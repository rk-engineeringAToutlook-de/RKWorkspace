## Zweck

Die Bilder sind keine finalen Produktgrafiken. Sie sichern die visuellen Hypothesen, damit der Owner die Wirkung vergleichen kann:

- echte Glasblase.
- lebendige Wasserlinse.
- Tunnel/Wurmloch.
- Raumkruemmung.
- Portal-Absorption.
- mobile Ablage-Linsen nach Geste.
