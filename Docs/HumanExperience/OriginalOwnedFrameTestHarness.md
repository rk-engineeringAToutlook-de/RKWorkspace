## Ablauf

1. Owner sieht Ding auf der eigenen Ablage.
2. Owner nimmt das Ding.
3. Genau eine gläserne Kante erscheint.
4. Owner legt das Ding in Richtung Zielablage.
5. Guest sieht Frame.
6. Owner erkennt: Original bleibt bei mir.
7. Owner gibt zurueck oder wartet auf Recovery.
