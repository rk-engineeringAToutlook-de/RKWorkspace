# MA016 Closed Open PDF Feeling Comparison

Status: Draft
Datum: 2026-07-07

## Zweck

MA016 fuehrt zwei PDF-Erlebnisse: geschlossene Kapsel und offener Frame. Dieses Dokument vergleicht die Human Experience beider Modelle.

## Geschlossene Kapsel

Der Owner erlebt ein Objekt, das an eine andere Ablage gegeben wird, ohne dass der Gast das Original erhaelt.

Soll-Gefuehl:

- geschuetzt
- ruhig
- transportierbar
- nicht editierbar

Risiko:

- kann wie Blackbox wirken
- kann wie Dateiuebertragung wirken
- kann zu wenig Kontext zeigen

## Offener Frame

Der Owner erlebt eine offene Arbeitsdarstellung, die auf einer anderen Ablage bedient werden kann, waehrend das Original owner-owned bleibt.

Soll-Gefuehl:

- weiterarbeiten
- praesent
- kontrolliert
- rueckholbar

Risiko:

- kann wie Remote Desktop wirken
- kann Sorge vor Fremdzugriff erzeugen
- braucht klare Rollenwahrnehmung

## Vergleichsfragen

1. Bei welchem Modell hast du weniger an Dateiuebertragung gedacht?
2. Bei welchem Modell war das Original fuer dich klarer geschuetzt?
3. Bei welchem Modell wolltest du eher weiterarbeiten?
4. Bei welchem Modell war der Rueckweg glaubwuerdiger?
5. Welches Modell passt besser zu "nehmen, tragen, ablegen"?

## Entscheidungsnotiz

Die geschlossene Kapsel ist der Sicherheitsanker. Der offene Frame ist der Produktpfad fuer Weiterarbeiten. Beide duerfen nicht gegeneinander ausgespielt werden; sie beantworten unterschiedliche Owner-Momente.
