# MA017 Frame Capsule Experience Test

Status: Draft
Datum: 2026-07-07

## Zweck

Dieser Test trennt die Wahrnehmung von Frame und Kapsel.

Eine Kapsel fuehlt sich geschlossen und geschuetzt an. Ein Frame fuehlt sich offen und bearbeitbar an. Beide Modelle muessen im MA017-Pilot klar unterscheidbar bleiben.

## HX-Bezug

- HX-001: Das gehoert zu meiner Arbeit.
- HX-001A: Das Objekt antwortet mir.
- HX-002: Ich habe etwas in meiner Hand.

## Erwartete Wahrnehmung

Kapsel:

- ruhig
- geschlossen
- geschuetzt
- nicht editierbar

Frame:

- offen
- praesent
- bedienbar
- rueckholbar

## Testfragen

1. Hast du verstanden, ob du gerade eine Kapsel oder einen Frame haeltst?
2. Hat die Kapsel sicher gewirkt?
3. Hat der Frame wie Weiterarbeiten gewirkt?
4. Gab es einen Moment, in dem beide Modelle gleich aussahen?
5. Hat das Modell zu deiner Absicht gepasst?

## Entscheidungskriterium

Gruen ist nur erreicht, wenn der Owner ohne technische Erklaerung unterscheiden kann:

```text
Kapsel = geschuetzt geben
Frame = weiterarbeiten
```
