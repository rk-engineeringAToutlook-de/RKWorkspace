# Digital Hand For Real Objects

Status: Draft  
Datum: 2026-07-06

## Ziel

AP162 beschreibt die digitale Hand fuer echte Objekte. Die Demo-Karte ist nicht das Ziel. PDF, Screenshot, Text, Window und Frame muessen sich wie tragbare Dinge anfuehlen.

## Objektarten

PDF:

- kompakter werden
- als Blatt/Frame wahrnehmbar bleiben
- keine Datei-Icon-Optik

Screenshot:

- als Ausschnitt wirken
- Kanten klar halten
- Inhalt nicht unlesbar verzerren

Text:

- als Notiz oder Textstueck wirken
- beim Tragen kompakt bleiben

Window:

- nicht wie Fenster ziehen
- als Arbeitsausschnitt oder interaktiver Frame erscheinen

Frame:

- klar machen: liegt hier, gehoert aber noch dem Owner

## Digitale Hand

Die digitale Hand ist keine sichtbare Comic-Hand. Sie entsteht durch Verhalten:

- Objekt wird kompakter
- Objekt wird teilweise verdeckt
- Objekt bekommt Tiefe
- Objekt folgt nicht perfekt dem Cursor
- Objekt besitzt weichen Schatten
- Objekt bleibt kontrollierbar

## Optische Haptik

Optische Haptik bedeutet:

- subtile Traegheit
- kleine Ausrichtung
- ruhige Stabilisierung
- keine Wackelanimation
- kein Glow als Ersatz fuer Verhalten

## Erfolgsfrage

Der Owner soll nicht sagen:

```text
Ich ziehe eine Datei.
```

Sondern:

```text
Ich habe das Ding gerade in der Hand.
```
