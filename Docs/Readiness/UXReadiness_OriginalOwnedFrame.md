# UX Readiness Original-Owned Frame

Status: Draft  
Datum: 2026-07-06

## Ziel

AP170 fasst den UX-Status fuer Original-Owned Frame zusammen.

## Bewertung

App-Gefuehl:

- Risiko: Developer- und Pilotoberflaechen wirken noch wie Apps.
- Ziel: Shell wirkt wie Arbeitsraum-Faehigkeit.

Ding-Gefuehl:

- teilweise vorhanden durch digitale Hand und Carry-Modelle.
- echte Objekte brauchen kompaktere, glaubwuerdigere Darstellung.

Frame-Verstaendnis:

- stark verbessert durch sichtbare Sprache: liegt im Frame, wartet auf Rueckgabe, wieder verfuegbar.
- Risiko: Guest darf nie freie Datei vermuten.

Kante:

- Produktpfad ist Single Glass Edge.
- visuelle Qualitaet bleibt wichtig, aber Funktion ist jetzt: naechste Ablage und Frame entsteht.

Haptik:

- plattformneutral vorbereitet durch `HapticHint`, `HapticPattern`, `HapticIntensity` und `HapticCapability`.
- echte Plattformimplementierungen fehlen noch.

Vertrauen:

- Original-Owned und No File Ingress sind die Grundlage.
- Fehler-UX muss immer bestaetigen: Original bleibt sicher.

Sprache:

- sichtbare UI vermeidet Senden, Empfangen, Upload, Download, Lease, Session und Peer.
- Diagnostics duerfen technisch bleiben.

## Abnahmestand

Bereit fuer weitere Pilot-Tests, wenn:

- Foundation Tests gruen sind.
- RKWP Tests gruen sind.
- Owner Feedback Log verwendet wird.
- UX-Fragen nach jedem Test beantwortet werden.

## Offene Punkte

- echte Plattformhaptik
- echte macOS/iPad Guest-Oberflaeche
- feinerer Glass-Edge-Renderer
- sichtbarer Owner-Test mit Feedbackprotokoll
