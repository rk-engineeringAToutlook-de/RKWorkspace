# MA013 Real Pilot Start Plan

Status: Accepted  
Datum: 2026-07-06

## Ziel

Der naechste echte Test ist Windows Owner zu macOS Guest. Danach folgt iPad/iPhone.

## Startreihenfolge

1. Windows lokalen Pilot mit Owner testen.
2. Context Pack erzeugen.
3. macOS-Codex mit Context Pack starten.
4. macOS Guest Surface bauen.
5. Windows Owner mit DevLan/SecureDev starten.
6. AblageHello, Identity, Session und Lease pruefen.
7. PDF Frame anzeigen.
8. Return und Recovery pruefen.
9. No File Ingress bestaetigen.
10. Danach iPad/iPhone Surface ueber Xcode testen.

## Gates

- No File Ingress ist nicht verhandelbar.
- Owner gewinnt bei Fehlern.
- Guest erhaelt keine Originaldatei.
- Audit ist verpflichtend.
- Glass Edge bleibt der UX-Pfad fuer die naechste Ablage.
