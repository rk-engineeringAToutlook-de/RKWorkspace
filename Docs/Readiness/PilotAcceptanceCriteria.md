# Pilot Acceptance Criteria

Status: Accepted  
Datum: 2026-07-06

## Ziel

Dieses Dokument definiert, wann der erste Real-Pilot als akzeptabel gilt.

## Muss-Kriterien

- Echte PDF wird auf der Owner-Ablage erkannt.
- No File Ingress bleibt erfolgreich.
- Guest sieht einen Frame, keine freie Datei.
- Return funktioniert.
- Recovery funktioniert nach Verbindungsverlust.
- Audit enthaelt Session, Lease, Frame, Return und Recovery.
- Owner ist waehrend Lease sichtbar gesperrt oder klar markiert.
- Guest besitzt keinen Originalpfad und keine Originalbytes.
- macOS-Pfad ist mindestens als Dev-Guest erreichbar.
- iPad-Pfad ist mindestens als Surface-Test vorbereitet.

## Nicht ausreichend

Der Pilot ist nicht akzeptiert, wenn nur eine lokale Demo laeuft, wenn der Guest eine Datei erhaelt oder wenn der Owner nicht wieder Kontrolle bekommt.
