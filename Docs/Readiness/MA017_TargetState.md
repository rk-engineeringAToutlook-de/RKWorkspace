# MA017 Target State

Status: Draft
Datum: 2026-07-07

## Ziel

MA017 fuehrt den MA016-Pilotpfad in die reale Plattformausfuehrung.

Der Zielzustand ist nicht "mehr Dokumentation", sondern ein reproduzierbarer Testpfad, in dem Windows als Owner-Ablage echte PDF-Objekte kontrolliert und macOS sowie iPad/iPhone als native Gastablaegen angebunden werden.

## Zielbild

- Windows Owner bleibt Ursprungseigentuemer.
- macOS Guest Surface oeffnet einen kontrollierten Frame.
- iPad/iPhone Guest Surface oeffnet einen kontrollierten Frame.
- No File Ingress bleibt hart.
- Glass Edge zeigt genau die naechste Ablage.
- Manual Map bleibt Fallback.
- UWB/Dongle werden fuer echte Naehe vorbereitet und simuliert getestet.
- Owner bewertet Human Experience, nicht Technik.

## Nicht-Ziele

- Kein produktiver Sync.
- Kein freier Datei-Transfer.
- Kein automatischer Ownership Transfer.
- Keine Cloud-Pflicht.
- Keine ungepruefte Produktionssicherheit.

## Erfolg

MA017 ist erfolgreich, wenn mindestens ein realer Plattformpfad mit Owner-Freigabe testbar ist und alle Sicherheitsregeln aus MA016 erhalten bleiben.
