# MA016 Pilot Roles

Status: Accepted  
Datum: 2026-07-07

| Rolle | Aufgabe |
| --- | --- |
| Windows Owner | fuehrt Original-PDF, Capsule/OpenFrame, Return und Recovery |
| macOS Guest | zeigt kontrollierte Frames ohne Datei-Ingress |
| iPad Guest | zeigt Frames per Xcode-App und bereitet Haptik/Sandbox vor |
| iPhone Guest | kompakte Surface fuer spaetere Capsule/OpenFrame-Tests |
| Dongle Anchor | spaeterer physischer Naeheanker fuer AblageIdentity und Distanz |
| Security Reviewer | prueft No File Ingress, Policy, Audit und DevMode-Warnungen |
| Owner Feedback Sensor | bewertet Wahrnehmung, Vertrauen, Kontrolle und Verstaendlichkeit |

## Owner-Sprache

Im Pilot wird nicht von Upload, Download, Transfer, Endpoint oder Device gesprochen. Sichtbare Sprache bleibt bei Ablage, Ding, Frame, Kapsel, liegt hier, zurueckgegeben, wieder verfuegbar und wiederhergestellt.
