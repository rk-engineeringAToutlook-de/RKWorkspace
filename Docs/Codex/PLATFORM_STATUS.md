# Platform Status

Datum: 2026-07-05

| Plattform | Status | Naechster Schritt |
| --- | --- | --- |
| Windows | Primaerer Testpfad, Native Glass Edge und Renderer-Spikes existieren | RKWP Frame Presenter an Native Glass Edge anbinden |
| macOS | Starter Kit mit FrameGuestSurface-Plan, Accessibility/Screen Recording/Sandbox-Hinweisen und kopierbarem Codex-Auftrag | macOS-Codex/Xcode-Kontext starten und FrameOnly Guest Surface bauen |
| iOS | Xcode-Handoff mit SurfacePlan, Permissions, Share Extension, Document Picker und PWA-nur-Uebergang-Regel | native iOS Surface App ueber macOS-Codex starten |
| iOS/iPadOS | Starter Kit fuer mobile Ablage, TouchHold/Drei-Finger-Pruefung, Haptik, Glass Edge und USB-Testpfad | iPad/iPhone FrameGuestSurface in Xcode vorbereiten |
| Android | Starter Kit fuer native Surface App, Sharesheet, Intent, Content URI, Clipboard, Haptik und PWA-nur-Uebergang | Android Studio/Gradle-Auftrag vorbereiten |
| Linux | Starter Kit fuer FrameGuestSurface/Agent, X11/Wayland/Portals, Headless und Industriepfad | Minimalen Linux Surface Host oder Agent planen |

Alle Plattformen muessen Entfernung/Naechste-Ablage aus gemeinsamen Proximity-Vertraegen behandeln.
