# iPhone Compact Capsule Layout Spec - MA016

## Goal

iPhone shows a compact capsule state for quick validation and later mobile guest behavior.

## Layout

- Compact card for the Ding.
- Minimal frame preview.
- One primary action: `zurueckgeben`.
- One status area.
- Optional lab diagnostics sheet.

## Behavior

- Long press opens capsule detail.
- Edge direction can be shown as a quiet glass edge.
- Return must be reachable with one hand.
- Recovery state must be readable without technical language.

## Constraints

- No visible technical transport vocabulary.
- No file picker for incoming owner PDF.
- No export of original file.
