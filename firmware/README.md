# Firmware

Dieses Verzeichnis ist fuer spaetere RK Workspace Dongle-Firmware vorgesehen. V1 dokumentiert Firmwarearchitektur, implementiert aber noch keinen Board-spezifischen Code.

Die Firmware soll spaeter eine Arbeitsflaeche repraesentieren, sichere Identitaet tragen, Discovery unterstuetzen, Pairing vorbereiten, optionale UWB-Positionsdaten liefern und Firmware-Updates ermoeglichen. Grosse Payloads sind nicht Aufgabe der Firmware.
