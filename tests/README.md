# Tests

Testbereiche:

- `Unit` prueft Core-Modelle, Services und Simulation.
- `Integration` ist fuer spaetere Agent-/Transport-Szenarien vorgesehen.
- `Protocol` ist fuer spaetere Kommunikations- und Nachrichtenfolgen vorgesehen.
- `Hardware` ist fuer spaetere Dongle- und UWB-Tests vorgesehen.
